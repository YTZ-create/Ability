# 27 种视觉类型一览（diagram-design）

按用途分类；每种对应一类可编辑 HTML 模板。类型编号 U01～U27。

## 流程 / 时序
1. **U01 流程图** — 顺序步骤 + 分支（`type-flow.md`）
2. **U02 泳道图** — 按角色/系统分区
3. **U03 时序图** — 对象间消息先后
4. **U04 决策树** — 条件分支路径
5. **U05 状态机图** — 状态与转移条件
6. **U06 时间线** — 里程碑/演进

## 架构 / 系统
7. **U07 系统架构图** — 模块分层与连接（`type-architecture.md`）
8. **U08 模块依赖图** — 依赖方向 ⊃ 反向引用
9. **U09 部署图** — 物理/云拓扑
10. **U10 数据流图** — 数据流转路径
11. **U11 ER 图** — 实体关系
12. **U12 类图** — 类/继承/组合
13. **U13 用例图** — 参与者与用例

## 组织 / 层级
14. **U14 组织结构图** — 上下级树
15. **U15 思维导图** — 主题辐射
16. **U16 树状图** — 目录/分类层级
17. **U17 甘特图** — 任务时间条

## 数据 / 对比
18. **U18 柱状图** — 类别对比
19. **U19 折线图** — 趋势
20. **U20 饼图/环形图** — 占比
21. **U21 散点图** — 相关分布
22. **U22 雷达图** — 多维度对比
23. **U23 热力图** — 密度矩阵
24. **U24 桑基图** — 流量分流

## 概念 / 综合
25. **U25 概念地图** — 概念与联系
26. **U26 对比表图** — 属性对照
27. **U27 仪表盘** — 关键指标总览
