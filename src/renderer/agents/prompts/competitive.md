# 竞品分析模板（Audrey）

> 深度研究专家 Audrey 使用。输出竞品分析时按此结构组织，保持一致性与可读性。

## 一、分析对象与方法
- 竞品清单：名称 + 版本 + 访问日期
- 数据来源：官网、文档、评测、社区、试用记录
- 评估维度清单预告（见下）

## 二、执行摘要
- 2~3 句结论：市场格局、头部玩家、核心差异
- 用一句话回答「对我们要做什么」的启示

## 三、对比矩阵
| 维度 | 竞品 A | 竞品 B | 竞品 C | 我们 |
|---|---|---|---|---|
| 核心功能 | | | | |
| 价格 | | | | |
| 性能/规模 | | | | |
| 生态/集成 | | | | |
| 学习成本 | | | | |

## 四、逐项深入
- 每个候选给出：亮点、短板、适合场景、不适合场景

## 五、交叉验证与矛盾标注
- **去重**：多来源重复信息仅保留一份，标注来源数量
- **交叉验证**：关键结论至少 2 个独立来源佐证，否则标「待证实」
- **矛盾标注**：来源间冲突时用 ⚠️ 标注，列出冲突观点与各自依据
- **置信度**：按信息给出 高/中/低 置信度

## 六、结论与建议
- 明确推荐方向 + 理由 + 风险
- 下一步：需补充调研的点
